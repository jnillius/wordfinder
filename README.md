# WordFinder
A web-based tool designed to help find words with very specific criteria. Created with the intention to be help with creating crypticles.

Currently hosted [here](https://wordfinder-szou.onrender.com/).

## Datasource
I have taken the words_alpha.txt file from [here](https://github.com/dwyl/english-words/blob/master/words_alpha.txt). The part of speech tag is from wordnet or if none is found it's generated by spaCy.

The definition of the words are also from wordnet. I think that is a reliable datasource but it a known problem is that for words with multiple meanings like "wave"(a hand gesture and a water wave) we only get one definition.

Therefore it should be noted that both the part of speech tag and the definition is not very reliable.
